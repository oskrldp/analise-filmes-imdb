# Análise de Filmes IMDB

Repositório de versionamento com Git e GitHub usando a base de dados tab_imdb.csv, com 100 filmes e 17 colunas (título, ano, gênero, duração, nota IMDB, orçamento, bilheteria, país e produtora).

## Objetivo

Praticar versionamento com Git e GitHub, usando commits, branches e revisão, tendo como base um conjunto de dados de filmes para análises futuras.

## Estrutura

- `dados/`: arquivo tab_imdb.csv
- `docs/`: documentação do projeto
